# MPFree's starter phrases: 64 written for MPFree, 16 of each kind. None is
# copied from Akai's phrases or from any other product's.

# Copy this file to write your own, and hear every phrase in a file with:
#   mpfree-arp-render --patterns my-phrases.txt
#
# One phrase per line: Name = kind scale [grid] [meter] [swung] [N bars] : steps | lanes
#   kind   bass, riff, chords or line: the shelf it sits on
#   scale  the scale it was written in: major, minor, or either
#   grid   what one step is: 1/8, 1/8T, 1/16 (when left out), 1/16T, 1/32, 1/32T
#   meter  4/4 (when left out) or 3/4
# Steps: . rest, _ tie, 1 to 7 a step of the scale from the note you hold
# (b or # lowers or raises it a half step, named from the major scale: a
# minor phrase writes b3, b6, b7), + or - an octave up or down, 1,3,5 notes
# together. After a note: ! accent, ' short, ~ held for the whole step.
# Lanes, each looping at its own length: vel, gate, nudge.
# Two spaces between bars are only for the eye.
