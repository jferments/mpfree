The file is unmodified and its licence allows bundling it with MIT software, as long as the licence travels with the font. The font keeps its own licence; the rest of MPFree stays MIT.

The Synthwave and Spaceship titles use MPFree's own blade letters (`src/blade.rs`), drawn as polygons in code, so they carry no font licence.

The Spaceship scene uses Inter and JetBrains Mono from `mpfree-ui`.
