# A tour of the MPC One

The pads, knobs, buttons and connectors, for someone who has never used an MPC, and what each one does in MPFree.

This chapter is not written yet. It will cover:

- The 16 pads and the four pad banks
- The four Q-Link knobs and the data wheel
- The transport buttons: PLAY, STOP, REC, OVERDUB
- SHIFT and MENU
- The mode buttons along the top
- The connectors: outputs, headphones, line inputs, MIDI, USB
