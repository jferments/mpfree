# About this manual

This manual is written alongside MPFree itself. Every time MPFree changes, the people building that change update the page that describes it, and the manual is rebuilt.

- **The screenshots are drawn by MPFree.** The manual's build asks MPFree to draw each of its pages and uses those pictures, so they always show the version the manual describes.
- **The banners tell you how settled a page is.** A page marked *Changing* describes something that works but is still being designed, so details may differ in a newer version. A page marked *Planned* describes something that is not built yet.
- **The website and the PDF are the same pages.** Read whichever suits you; print the PDF if you like paper beside your MPC.
